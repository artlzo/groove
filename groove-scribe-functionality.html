Groove Scribe — functionality reference

Click any section to expand. Pulled directly from the source code.

Playback
Play / Pause
Click the play button to start MIDI playback. Click again to stop.
BPM
Drag the BPM slider or use ← → arrow keys to adjust tempo. Default is 80.
Swing
Drag the Swing % slider to add swing feel to the groove.
Loop
Playback loops continuously through all measures until stopped.
Metronome
OptionWhat it does
OFFNo click track
4thClick on every quarter note
8thClick on every 8th note
16thClick on every 16th note
SoloMutes the groove — plays only the metronome
Auto speed upRaises tempo by a configurable BPM amount at a configurable interval (minutes)
Count it inPlays one measure of metronome count before the groove starts
Offset clickShifts when the click falls — start on 1, E, &, A, or rotate through all. Triplet-aware.
Time signature & subdivision
ControlOptions

Measures
Add measure
Adds a new blank measure to the right. Max 10 measures.
Remove measure
Removes the last measure. Click the × on any measure.
Multi-measure looping
Playback loops through all measures in sequence.
Permutations

Only available in 4/4 time. Generates variations of the groove across multiple measures automatically.

TypeWhat it generates
NoneOff — standard groove editing
Kick permutationCycles kick pattern through 16th-note positions
Snare permutationCycles snare pattern through 16th-note positions
Grooves library

Click Grooves in the top nav to open a dropdown of preset grooves. Selecting one loads it directly into the editor, replacing the current groove.

View / edit mode

"Switch to VIEW mode" hides all editing controls, leaving only the sheet music and player — useful for performance or display. Click "Switch to EDIT mode" to restore. The mode is encoded in the URL.
